# 📋 Projeto 1 - Formulario em react 

Este projeto foi desenvolvido como requisito para a disciplina de Interface Grafica. 

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes bibliotecas vistas em sala de aula:

* **[React](https://reactjs.org/):** Construção das interfaces de usuário.
* **[React Router v6](https://reactrouter.com/):** Gerenciamento das rotas (Navegação sem recarregar a página).
* **[Formik](https://formik.org/):** Gerenciamento do estado e submissão do formulário.
* **[Yup](https://github.com/jquense/yup):** Criação dos esquemas de validação de dados.
* **CSS Nativo:** Estilização global e dos componentes.

## ⚙️ Funcionalidades

* **Navegação SPA:** Transição fluida entre a Página Inicial, Formulário e Sobre.
* **Validação de Dados:** Campos obrigatórios controlados com exibição de mensagens de erro (ex: idade, avaliação do serviço).
* **Tratamento de Exceções:** Rota coringa (`*`) implementada para capturar URLs inválidas e redirecionar para uma página customizada de Erro 404.

## 💻 Como executar o projeto localmente

Para rodar este projeto na sua máquina, você precisará do [Node.js](https://nodejs.org/) instalado.

1. Faça o clone do repositório:
   git clone URL_DO_SEU_REPOSITORIO_AQUI
2. Entre na pasta do projeto:
   cd projeto-satisfacao
3. Instale as dependências:
   npm install
4. Inicie o servidor local:
   npm start
   
O navegador abrirá automaticamente a aplicação em http://localhost:3000.
